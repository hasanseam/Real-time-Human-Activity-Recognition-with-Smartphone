# Real-time Human Activity Recognition with Smartphone

This Android project is a pivotal part of my Master's thesis, focusing on real-time human activity recognition using smartphone sensors. The project is bifurcated into two primary components: data acquisition and data prediction.

## Overview

### Data Acquisition
The application enables users to collect sensor data pertaining to various activities such as running, walking, and more. Leveraging the smartphone's sensors, it captures and stores this data for further analysis and prediction.

### Data Prediction
The app employs machine learning models to predict and identify the current activity of the user based on the collected sensor data. Using Java within the Android Studio environment, the predictions are made in real-time, providing users with immediate feedback on their current activity.

## Usage
Upon launching the application on your device, you can explore the following activities:

### Data Acquisition
1. Select the 'Data Acquisition' section within the application.
2. Choose the activity you want to record (e.g., running, walking, standing).
3. The application will start collecting sensor data related to the chosen activity.

### Data Prediction
1. Navigate to the 'Data Prediction' section.
2. The app will use the collected sensor data to predict and display the current activity you are performing in real-time.
